# React + Vite + Bun

Este proyecto fue creado utilizando **React** como librería de interfaz de usuario, **Vite** como herramienta de build y **Bun** como runtime y gestor de dependencias.

---

## Requisitos previos

Antes de comenzar, asegurate de tener instalado **Bun**.

Verificar instalación:
bun --version


Despues en caso de  no tener instalado Bun

bun install

bun run dev



```bash
bun run dev
Inicia el servidor de desarrollo.

bun run build
Genera la build de producción.

bun run preview
Permite previsualizar la build de producción.
